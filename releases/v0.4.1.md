## 中文

本版本在 0.3.1 的输出工具基础上增加 `list_edit()`，用于录入和调整 marker genes、绘图颜色及细胞类型顺序。`out()`、`outputs()` 和 `ggsave1()` 继续保留；列表编辑及配套窗口、参数和文档改进统一归入 v0.4.1。

### 本次更新

- ✨ 新增：逐列输入、粘贴、拖动排序、撤销／重做，以及 CSV 导出和 R 代码预览。各列独立，默认一列返回字符向量，多列返回命名 list；需要固定类型时可指定 `output = "list"` 或 `"vector"`。
- ✨ 新增：通过 `file` 导入 CSV、TSV 等 UTF-8 分隔文本。`fread()` 自动识别分隔符，按字符读取，保留 `001`、文本 `NA` 和非空内容两侧空格；列名必须非空且唯一，解析警告会转为错误。
- ✨ 新增：Windows 优先使用 Edge/Chrome 独立窗口，找不到支持的程序时使用默认浏览器；保留显式 `viewer = "dialog"` 和 `"browser"`。快捷键以按键标签显示。
- 📚 文档与维护：统一参数帮助和中英文 README，增加输出管理、列表编辑两篇双语教程，配置 pkgdown 开发预览与正式 Release 文档部署流程。
- 📦 依赖更新：增加必需依赖 `data.table`。交互编辑另需可选依赖 `shiny`、`jsonlite`；RStudio 对话框模式另需 `rstudioapi`。无需安装 DataEditR。

### 安装与使用

从 GitHub Releases 下载对应源码包后，将示例路径替换为下载位置；也可安装本地构建的源码包。安装前重启已加载旧版 cic 的 R 会话。

```r
install.packages(c("data.table", "fs", "ggplot2", "shiny", "jsonlite"))
install.packages("path/to/cic_0.4.1.tar.gz", repos = NULL, type = "source")
cell_order <- cic::list_edit()
```

### 限制与验证

编辑期间当前 R 会话等待窗口完成；取消会报错并保留赋值目标的原值。各列独立，不适合成对重排细胞类型与颜色。独立窗口不保证始终置顶；RStudio 对话框受宿主窗口限制。导出为 CSV；Excel 和 R 二进制文件不支持直接导入。

Windows / R 4.4.1 上的 `R CMD check --no-manual` 通过（Status: OK），包含四个 R 测试文件和教程重建。JavaScript 交互逻辑测试通过；pkgdown 开发站的 15 个 HTML 页通过本地链接和锚点检查。文档构建仍有本机依赖的 `xfun::attr()` 弃用提示。窗口移动、缩放与拖放的人工验收，以及 GitHub 工作流部署验收尚未完成。

## English

This version adds `list_edit()` to the output tools in 0.3.1, for entering and reordering marker genes, plotting colours and cell-type orders. `out()`, `outputs()` and `ggsave1()` remain available. The editor and its window, argument and documentation improvements are delivered together in v0.4.1.

### What's Changed

- ✨ Features: Independent column entry, paste, drag reordering, undo/redo, CSV export and R code preview. One column returns a character vector by default; multiple columns return a named list. Set `output = "list"` or `"vector"` for a fixed return type.
- ✨ Features: Import CSV, TSV and other UTF-8 delimited text through `file`. `fread()` detects separators and reads character values, preserving `001`, literal `NA` and surrounding whitespace. Names must be non-blank and unique; parser warnings become errors.
- ✨ Features: Prefer an independent Edge/Chrome window on Windows, falling back to the default browser when no supported executable is found. Explicit `viewer = "dialog"` and `"browser"` remain available. Keyboard instructions use key labels.
- 📚 Docs & Chores: Align parameter help and bilingual READMEs, add two bilingual guides, and configure pkgdown development previews and documentation deployment for formal Releases.
- 📦 Dependencies: Add required dependency `data.table`. Interactive editing also needs optional packages `shiny` and `jsonlite`; RStudio dialog mode needs `rstudioapi`. DataEditR is not required.

### Installation and usage

Download the source package from GitHub Releases and replace the example path with its location, or use a locally built archive. Restart R before upgrading if an older cic version is loaded.

```r
install.packages(c("data.table", "fs", "ggplot2", "shiny", "jsonlite"))
install.packages("path/to/cic_0.4.1.tar.gz", repos = NULL, type = "source")
cell_order <- cic::list_edit()
```

### Limitations and verification

The current R session waits for editing to finish. Cancellation raises an error and preserves the assignment target. Columns are independent and unsuitable for reordering paired cell types and colours. Independent windows are not guaranteed to stay on top; RStudio dialogs retain host-window restrictions. Export uses CSV; Excel and R binary files cannot be imported directly.

On Windows / R 4.4.1, `R CMD check --no-manual` passed (Status: OK), including four R test files and vignette rebuilding. JavaScript interaction-logic tests passed. Local links and anchors passed in 15 HTML pages of the pkgdown development site. Local documentation dependencies still emit `xfun::attr()` deprecation warnings. Manual checks of window movement, resizing and drag/drop, and deployment validation of the GitHub workflows, remain outstanding.
